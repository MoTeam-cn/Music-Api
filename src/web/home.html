music-api v__VERSION__

公开音乐元数据聚合接口：网易云 / QQ 音乐 / 酷狗 / 百度音乐。只读、零依赖、支持 JSONP。

免责声明：仅供技术研究与学习。只聚合各平台公开可访问的网页数据，不存储、不转码、不分发音频，不提供 VIP/付费内容，不含登录、破解或绕过版权保护的能力。使用时请遵守所在地区法律与各平台服务条款。

接口

  • GET /v1/search — 搜索，参数 q、source（默认 all）、type（默认 song）、page、size
  • GET /v1/song — 单曲详情，参数 source、id
  • GET /v1/song/url — 公开可播直链，参数 source、id、quality
  • GET /v1/lyric — LRC 歌词，参数 source、id
  • GET /v1/album — 专辑详情，参数 source、id
  • GET /v1/artist — 歌手与热门曲目，参数 source、id
  • GET /v1/playlist — 歌单详情与曲目，参数 source、id、page、size（每首带 available / vip 标记）
  • GET /v1/rank — 榜单列表 / 榜单详情，参数 source、id（可省）
  • GET /v1/source — 四源能力矩阵
  • GET /v1/status — 版本与运行状态
  • GET /openapi.json — OpenAPI 3.0 文档

source 取值：netease / tencent / kugou / baidu；quality 取值：standard / high / lossless。

示例

JSON：

GET /v1/search?q=晴天&source=netease&size=5&origin=web
GET /v1/playlist?source=netease&id=3778678&page=1&size=50&origin=web
GET /v1/song/url?source=netease&id=2652820720&origin=web

所有 /v1 接口必须带 origin（如 origin=web / origin=app-ios），用于区分来源；缺失返回 1001。静态页与 /openapi.json 不要求。

UA 过滤：okhttp / python-requests / axios / undici / postman 等库默认 UA 会被拦截（4002 / 403），浏览器与 curl/wget 正常。

JSONP（浏览器跨域，本服务不设 CORS 头，只能用 JSONP）：

<script>
  function onSearch(res) {
    if (res.code !== 0) return console.error(res.message);
    console.log(res.data.list);
  }
</script>
<script src="/v1/search?q=晴天&source=netease&callback=onSearch&origin=web"></script>

jQuery：$.ajax({ url: '/v1/search', dataType: 'jsonp', data: { q: '晴天', origin: 'web' } })

浏览器 SDK（推荐）

一个 <script> 引入，SDK 自动处理 JSONP、超时、缓存、去重、参数校验与播放，调用方不用自己拼回调：

<script src="/sdk.js"></script>
<script>
  MusicApi.search({ q: '晴天', source: 'netease', size: 5 })
    .then(function (res) { console.log(res.data.list); })
    .catch(function (err) { console.error(err.code, err.message); });

  MusicApi.playlist({ source: 'netease', id: '3778678', page: 1, size: 50 })
    .then(function (res) { return MusicApi.play(res.data.song[0]); });
</script>

可配置参数（<script data-*> 属性或 MusicApi.configure()）：baseUrl、origin、source、quality、timeout、retries、cache、cacheTtl、throwOnError、signal、onRequest / onResponse / onError。

方法：search / song / songUrl / lyric / album / artist / playlist / rank / sources / status / play；类型声明见 /sdk.d.ts，完整文档见仓库 docs/sdk.md。

响应

{ "code": 0, "message": "ok", "data": {}, "source": "netease", "cost": 137 }

错误码：1001 参数 · 1002 源 · 1003 能力 · 1004 方法 · 2001 超时 · 2002 上游 · 2003 解析 · 3001 不存在 · 3002 VIP/付费 · 4001 限流 · 4002 UA 被拦截 · 5000 内部。JSONP 模式下 HTTP 恒为 200，错误只看 code。

说明

  • 本项目只提供接口，不含播放器页面，二次开发请自行接入 UI 与播放逻辑。
  • VIP / 付费曲目只返回元数据（available=false），取播放地址返回 3002。
  • 播放直链有时效，拿到后请立即播放，不要持久化。
  • 完整文档见 /openapi.json，免责声明见仓库 DISCLAIMER.md。
