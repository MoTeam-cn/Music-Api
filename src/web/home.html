music-api v__VERSION__

公开音乐元数据聚合接口：网易云 / QQ 音乐 / 酷狗 / 百度音乐。只读、零依赖、支持 JSONP。

免责声明：仅供技术研究与学习。只聚合各平台公开可访问的网页数据，不存储、不转码、不分发音频，不提供 VIP/付费内容，不含登录、破解或绕过版权保护的能力。使用时请遵守所在地区法律与各平台服务条款。

接口

  • GET /v1/search — 搜索，参数 q、source（默认 all）、type（默认 song）、page、size
  • GET /v1/song — 单曲详情，参数 source、id
  • GET /v1/song/url — 公开可播直链，参数 source、id、quality
  • GET /v1/lyric — LRC 歌词，参数 source、id
  • GET /v1/album — 专辑详情，参数 source、id
  • GET /v1/artist — 歌手与热门曲目，参数 source、id
  • GET /v1/playlist — 歌单详情与曲目，参数 source、id、page、size、with_url（=1 直接带播放地址）、quality
  • GET /v1/rank — 榜单列表 / 榜单详情，参数 source、id（可省）
  • GET /v1/source — 四源能力矩阵
  • GET /v1/status — 版本与运行状态
  • GET /openapi.json — OpenAPI 3.0 文档

source 取值：netease / tencent / kugou / baidu；quality 取值：standard / high / lossless。

示例

JSON：

GET /v1/search?q=晴天&source=netease&size=5
GET /v1/playlist?source=netease&id=3778678
GET /v1/song/url?source=netease&id=2652820720

JSONP（浏览器跨域，本服务不设 CORS 头，只能用 JSONP）：

<script>
  function onSearch(res) {
    if (res.code !== 0) return console.error(res.message);
    console.log(res.data.list);
  }
</script>
<script src="/v1/search?q=晴天&source=netease&callback=onSearch"></script>

jQuery：$.ajax({ url: '/v1/search', dataType: 'jsonp', data: { q: '晴天' } })

响应

{ "code": 0, "message": "ok", "data": {}, "source": "netease", "cost": 137 }

错误码：1001 参数 · 1002 源 · 1003 能力 · 1004 方法 · 2001 超时 · 2002 上游 · 2003 解析 · 3001 不存在 · 3002 VIP/付费 · 4001 限流 · 5000 内部。JSONP 模式下 HTTP 恒为 200，错误只看 code。

说明

  • 本项目只提供接口，不含播放器页面，二次开发请自行接入 UI 与播放逻辑。
  • VIP / 付费曲目只返回元数据（available=false），取播放地址返回 3002。
  • 播放直链有时效，拿到后请立即播放，不要持久化。
  • 完整文档见 /openapi.json，免责声明见仓库 DISCLAIMER.md。
